Inspect Android app HTTP requests and responses directly in Android Studio.

OkHttpSniffer displays traffic from OkHttp clients instrumented with its companion Android interceptor. Inspect API calls alongside your code, including Retrofit calls made through the configured OkHttp client.

  • View request methods, URLs, response status codes, and recorded durations.
  • Inspect request and response headers, raw bodies, formatted JSON, and JSON trees.
  • Copy request URLs, response bodies, and cURL commands.
  • Generate Java or Kotlin Gson models from JSON nodes.
  • Select a connected Android device and an available app process.

Requirements

Android Studio, a connected device or emulator, and a debuggable Android app using the companion interceptor. The runtime is published on JitPack as com.github.mobcoding:OkHttpSniffer:1.1.3. It requires Android API 21 or later and an app-provided OkHttp dependency; it is compiled against OkHttp 4.12.0.

Capture applies only to requests made through the instrumented OkHttp client. This is not a system-wide network sniffer or a TLS interception proxy. Request bodies and responses are subject to capture and display limits.

Debug data

Enable the interceptor only in debug builds. It writes captured HTTP data to Android Logcat, which the IDE plugin reads through ADB. Headers and bodies may contain credentials or personal data; use test data and redact exports before sharing them.
