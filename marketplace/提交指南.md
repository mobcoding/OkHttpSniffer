## 4. 兼容性和发布前验证

当前源码声明 `since-build=261`，没有 `until-build`，并以 Java 21 为目标。此前构建针对本机 Android Studio 2026.1.3，完整 build number 为 `AI-261.26222.65.2613.15948027`。

这只能说明声明范围和已有构建环境，不能证明所有 261 平台版本或所有未来 Android Studio 版本都能运行。上架前对实际宣称支持的 Android Studio 安装版运行 Plugin Verifier 和沙箱运行验证，再决定 since-build / until-build。Java 21 是 IDE 运行环境/构建要求，不是要求被抓包的 Android 应用运行 Java 21。

已有任务 `verifyPluginStructure` 只验证插件包结构，不等同于 Plugin Verifier 的 API 兼容性验证，也不等同于真实设备抓包测试。

提交前待完成：

- 检查最终 JAR 内的 `META-INF/plugin.xml` 与 Logo，而不只是源码文件。
- 确认 Marketplace 账户中的 Vendor 联系邮箱、许可证链接和截图；上架候选包已将工具栏入口指向你的文档和 GitHub Issues。
- README 和本资料 Getting started 已统一为 debug/release source set 示例，避免 `debugImplementation` 配合 `src/main` 直接引用拦截器导致 release 编译失败；接入时请分别验证应用的 debug 与 release 构建。
- 验证安装、设备/进程选择、响应完成后的详情更新、清空、cURL 和模型生成；在至少一个真实设备或模拟器上测试。
- 运行最终包的构建、测试、结构检查以及 Plugin Verifier，检查已打包依赖与声明范围。
- 在实际 IDE 中核对深浅主题图标并拍摄上述截图。
- 对照实现确认 `privacy.md` 的陈述；将正式隐私说明和文档发布到可公开访问的地址。

构建命令（沿用当前环境）：

```powershell
.\gradlew.bat clean test buildPlugin verifyPluginStructure -PStudioCompilePath="C:\Program Files\Android\Android Studio"
```

发行文件使用重新构建的 IDE 插件 ZIP。不要上传 JitPack AAR、源码 ZIP 或仓库内的旧版插件 ZIP 作为本次版本。

## 5. 提交流程

1. 登录 JetBrains Marketplace；首次上传需接受 Developer Agreement 并建立 Vendor profile。
2. 在账户菜单选择 Upload plugin，按页面选择 IDE 插件类型并上传准备好的插件 ZIP。官方最大包大小为 400 MB，当前历史包约 2.3 MB。
3. 填写许可证、源码地址、标签及联系信息，核对从包内提取的名称、版本和兼容产品。
4. 使用本目录的英文介绍、Getting started 和更新日志，在页面预览中检查 HTML 格式。
5. 在 Media 中添加真实截图；填入支持链接与公开隐私说明地址（若页面提供该字段）。
6. 提交审核；公开发布以 Marketplace 审核结果为准，不承诺固定审核时长。

如审核表单或审核人员需要说明 fork 来源，可复制以下文案；仅在已完成独立 ID/branding 后使用：

> OkHttpSniffer is an independently maintained fork of the Apache-2.0-licensed OkHttp Profiler project. The submission uses its own plugin ID and branding. Upstream attribution is retained in the source and repository notices. The companion Android runtime is available as com.github.mobcoding:OkHttpSniffer:1.1.4. This plugin inspects requests from instrumented Android apps through ADB and Logcat; it does not capture arbitrary device traffic or decrypt TLS through a proxy.

你需要提供或操作的账号信息：Marketplace 登录、Vendor profile、可接收通知的联系邮箱和 Developer Agreement 的接受。无需向文档或仓库写入登录密码/发布 token。
