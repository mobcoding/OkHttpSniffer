First Marketplace release of OkHttpSniffer, independently maintained by mobcoding.

  • Introduce independent plugin branding and a companion Android runtime published on JitPack.
  • Update the build toolchain and migrate Logcat integration to the current Android Studio platform.
  • Improve capture cleanup and request isolation when switching devices or processes.
  • Refresh selected request details as responses arrive and correct error highlighting for HTTP 400.
  • Correct raw response formatting, body size checks, and cURL quote escaping.
  • Improve generated model identifiers, nested type references, and package selection.
  • Use compact IDE toolbar icons and a bundled welcome page.

Android runtime dependency: com.github.mobcoding:OkHttpSniffer:1.1.3.
